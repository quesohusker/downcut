              About Kerfline

              CNC CAD/CAM for routers. Kerfline is not made by or connected with Vectric.

              The Hershey Fonts were originally created by Dr. A. V. Hershey while working at the U. S. National Bureau of Standards. The format of the font data in this distribution was originally created by James Hurt, Cognition, Inc.

              PDF reading uses pypdf. Geometry uses Shapely and GEOS. Text shaping uses HarfBuzz and fontTools.

              Before you start

              Kerfline is test software. It has not been run on a real CNC machine by its author.

              Bad G-code can break bits, ruin material, damage machines, and hurt people. The built-in checker cannot catch every mistake.

              Read every file before you run it. Air-cut it above the material first. Keep a hand near the stop. Feeds and speeds are starting values only. You use this software at your own risk.
